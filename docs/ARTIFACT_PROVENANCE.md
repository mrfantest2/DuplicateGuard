# Artifact provenance

The historical ZIPs and v2.3.0 installer were recovered from the owner's ChatGPT file library. The v2.3.0 installer was also deployed and executed on the Master PC during recovery, where the application installed successfully under the current user's Local AppData Programs directory and served its loopback dashboard.

The source tree committed to `main` was extracted byte-for-byte from `DuplicateGuard_v2.1.1_Source.zip` before repository documentation/CI files were added.

See `release/checksums-SHA256.txt` for hashes of every preserved original artifact.

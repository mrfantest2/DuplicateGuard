# Release artifact manifest

The v2.3.0 GitHub release is an archival/recovered release.

- `DuplicateGuard_v2.3.0_Setup_Windows_x64.exe` — latest authentic recovered installer.
- `DuplicateGuard_v2.1.1_Source.zip` — latest authentic recovered source archive.
- `DuplicateGuard_v2.1.0_Source.zip` — recovered v2.1.0 snapshot A.
- `DuplicateGuard_v2.1.0_Source.1.zip` — recovered v2.1.0 snapshot B, distinct from snapshot A. Original archived filename: `DuplicateGuard_v2.1.0_Source(1).zip`; GitHub normalizes parentheses in release asset names.
- `DuplicateGuard_v2.0.0_Source.zip` — recovered historical source.
- `DuplicateGuard_v1.0.0_Source.zip` — earliest recovered source.
- `checksums-SHA256.txt` — SHA-256 hashes for all of the above.

The tag/release does not assert that the repository's v2.1.1 source reproduces the historical v2.3.0 installer byte-for-byte.
